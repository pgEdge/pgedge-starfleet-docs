# Getting Started with pgEdge Starfleet BYOC

Getting started with pgEdge Starfleet BYOC is easy; simply
navigate to 
[the pgEdge sign-in page](https://app.pgedge.com/login?plan=developer&screen_hint=signup)
and follow the provided link to create an account, or log in with your Google
or GitHub account.

BYOC has two deployment options; you can deploy: 

* a pgEdge-managed single-node PostgreSQL database. pgEdge-managed databases
  are provisioned on AWS, providing an easy way to deploy PostgreSQL without
  the extra work involved behind the scenes.

* a self-managed cluster (optionally multi-region and multi-active) that is
  provisioned in your own cloud account.

For detailed information about creating a pgEdge managed database, visit
[here](managed/creating_managed.md).
    
For detailed information about creating a self-managed cluster using your own
cloud account, visit [here](self_managed/creating_self_managed.md).
