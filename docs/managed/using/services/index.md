# Services

The `AI Services` pane on your database's management page displays icons you
can use to deploy available services on your database.

![The AI Services pane](../../../images/managed_services.png)

Select `Enable MCP` to deploy an [MCP Server](mcp.md), or select `Enable RAG`
to deploy a [RAG Server](rag.md). Once a service is deployed, select its
`Details` button to view connection details and manage it.
